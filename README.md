# Лабораторная 17.3: Выделение подстроки без стандартных функций

Функция `substr` копирует подстроку из исходной строки в готовый буфер, используя только ручное копирование и указатели (без `strcpy` и `malloc`).

## Структура проекта:
- `include/strings.h` — интерфейс модуля
- `src/strings.c` — реализация
- `src/main.c` — автоматические тесты
