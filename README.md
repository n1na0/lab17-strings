# Лабораторная 17.3: Выделение подстроки

Функция `substr` копирует подстроку из исходной строки в готовый буфер, используя только ручное копирование и указатели

## Структура проекта:
- `include/strings.h` — интерфейс модуля
- `src/strings.c` — реализация
- `src/main.c` — автоматические тесты
## Сборка и запуск
gcc -std=c99 -Wall -Wextra -Iinclude src/strings.c src/main.c -o substr_test
./substr_test
